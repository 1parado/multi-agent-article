这个站是什么

2026 年前后，各家大模型在基准上的差距收窄到 2–5% 的窄带，「模型之外的结构」成为新的性能主战场：怎么把多个 agent 组织起来（framework）、怎么包裹模型控制它的每一步（harness）、怎么让它自生成与自我纠偏、怎么保证多主体交互下的安全。

本站以「一页读懂一篇」的方式，为 11 篇相关论文提供中文编译页（解决什么问题 → 创新点 → 关键结果 → 局限），并配横向对比表与建议阅读顺序，作为个人学习笔记，也希望能帮同好降低入门门槛。

收录标准与范围

  • 主题互补：围绕 multi-agent 编排 / agent harness / 自生成 / 安全 / 路由与去中心化协调，避开与已收录篇目高度重复的工作；
  • 代表性优先：优先收录引发讨论或方法上有原创性的 arXiv 工作（含已中稿会议/研讨会者，如 ICLR 2026）；
  • 人工核验：每篇的中文页基于 arXiv 摘要与正文撰写，关键数字逐一核对原文后再落笔。

收录时间范围为 arXiv 2025-09 ～ 2026-09（个别篇目编号早于 2026 但以 2026 年发表/会议版本为准，如 #08 MAS² 为 arXiv 2509、ICLR 2026 Poster）。新增论文会追加到目录末尾并更新本篇的收录时间。

怎么读这个站

建议先读 目录页 的「建议阅读顺序」，再按兴趣进入单篇；每篇页面右侧 ☰ 可随时查看章节目录，正文中带点状下划线的词可在 术语表 查解释。若想留存或引用，每篇页首都有「引用 BibTeX / APA」一键复制；用浏览器打印（Ctrl/Cmd+P）即可导出该页为 PDF，悬浮控件会自动隐藏。

维护者与反馈

本站由 Paradox 个人维护，源码公开于 github.com/1parado/multi-agent-article（纯静态、无构建依赖，可直接双击 index.html 浏览）。发现数字错误、断链或想推荐论文，欢迎提 GitHub Issue。
