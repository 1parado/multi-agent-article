# Visual Aesthetics Improvements

> 本 PR 汇总从产品经理 / 用户体验角度提出的**页面美观层面**优化建议，全部可在纯静态 GitHub Pages 站点落地，无需后端或数据库。

## 目标

在不改变现有信息架构与功能的前提下，提升整体视觉质感、可读性与专业感。

## 优化关键词与建议

### 1. 对比度与可读性
- 当前首页部分定义文字、次要信息颜色过浅（浅灰），在弱光或移动端几乎不可读。
- 系统性检查 `--soft` / `--gray` 使用场景，确保正文与辅助文字达到 WCAG AA 对比度。
- 水印、背景装饰元素透明度再调低或条件显示，避免干扰正文。

### 2. 视觉节奏与留白
- 统一章节间距、卡片内边距、段落呼吸感。
- 避免「信息过密」与「空白过大」的极端，建立更一致的垂直节奏。

### 3. 字体层级精炼
- 标题、副标题、正文、辅助信息（meta / pubmeta）的字重与字号梯度再清晰化。
- 确保中英文混排时视觉权重协调。

### 4. 色彩系统收敛
- 红色主调 + 分类色目前较好。
- 统一 hover / active / disabled / focus 状态的颜色与过渡。
- 减少临时硬编码颜色，尽量走 CSS 变量。

### 5. 卡片与封面质感
- 画廊视图卡片：阴影、圆角、hover 抬升效果可更精致统一。
- 封面图（covers/）风格已统一，后续新增需严格遵循既有规范。

### 6. 装饰元素克制
- 水印、背景纹理、分隔线避免与正文抢视觉焦点。
- 优先保证「内容第一」。

### 7. 暗色模式适配（可选）
- 对夜间长文阅读价值较高。
- 可用 `prefers-color-scheme` 或手动切换按钮实现，纯 CSS 变量即可。

### 8. 响应式细节打磨
- 超窄屏与超宽屏下的布局断裂、元素溢出、触控目标大小再检查。
- 移动端卡片与筛选栏的间距优化。

### 9. 图标与符号统一
- 导航、操作、状态图标风格保持一致（线条粗细、圆角、颜色）。

### 10. 打印与导出美观
- 现有打印样式已隐藏悬浮控件。
- 可进一步优化分页、重点内容保留、颜色打印准确性。

## 建议优先级

| 优先级 | 项 |
|--------|----|
| 高 | 对比度与可读性、视觉节奏与留白、字体层级 |
| 中 | 色彩系统收敛、卡片质感、响应式细节 |
| 低 | 暗色模式、图标统一、打印优化 |

## 实现约束

- 纯前端（CSS / 少量 JS）
- 不引入构建工具或外部依赖
- 保持与 `AGENT.md` 规范兼容
- 向后兼容现有页面结构
